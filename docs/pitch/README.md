## Product truth

All device screens are **speculative designs**, not screenshots of shipped capabilities. The draft native Android photo-and-marker prototype is distinct from planned catalog search, AI survey, AYA sharing, and output import. In the proposed workflow, Retrofit owns local photo/annotation data and frozen review; AYA mediates a user-approved outgoing share to the person's selected external agent. **AYA neither generates an image nor automatically retrieves an agent result**. Return requires the user to save and import an image. Generated concept images are not engineering designs, verified product fits, geometry proofs, or demonstrated unchanged-pixel output.
