# Retrofit

Native Android app for creating client-facing **concept visualizations** of building equipment retrofits.

Import a mechanical-room photograph, annotate positions, describe changes, attach precise reference equipment, and review a user-authorized handoff to a preferred agent through [AYA](https://github.com/gamesbyian/AYA). AI output is a proposal, not validated engineering.

- [First vertical-slice execution issue](https://github.com/gamesbyian/retrofit/issues/1)
